# ADR-0029: 各主成分がどんな文書の性質や語と対応するかを、文書の属性との r² と、語ごとの標準化平均差 δ で調べる

- Status: Accepted
- Date: 2026-10-26

## 背景

文書の平均を引き上位の主成分を除くと、ほとんどの層で nDCG@1000 が上がった (`pc_removal`、
issue #47)。`cl-tohoku/bert-base-japanese-v3` の層 0 (NTCIR-1) では、上位から何本目までの
主成分を除くかによって次のように変わった。

| 除いた主成分 | nDCG@1000 |
|---|---|
| なし (平均を引いただけ) | 0.198 |
| PC1 | 0.230 |
| PC1〜2 | 0.316 |
| PC1〜20 | 0.389 |
| PC1〜200 | 0.319 |

層 0 の主成分を観察して、次の仮説を立てた。

- PC1 は文書長の成分。除くと文書長が正規化される
- PC2 は助詞と形式名詞の成分。除くと頻出語が除かれる
- PC3〜20 は広い分野の語の成分。除くと、より細かい分野ごとの語を扱えるようになる

ある仮説 (例: 文書長) が、仮説を立てた主成分 (PC1) 以外の主成分とも関係していないかを
確かめるため、すべての仮説をすべての主成分について同じ手順で調べる。

## 決定

### 対象

- モデルは `cl-tohoku/bert-base-japanese-v3`。スクリプトはモデルの識別子を差し替えれば
  ほかのモデルでも回せるようにする
- コレクションは NTCIR-1 と NTCIR-2。スクリプトを回すときに指定する
- 全 13 層を同じ手順で扱う。仮説は層 0 で立てたが、層 0 を特別扱いしない
- 主成分は `pc_removal` と同じく、層ごとに文書の平均を引いてから推定し、200 本目まで計算する
- 文書 d の主成分 k の得点を s_k(d) = (x_d − x̄) · u_k とする。x_d はその層での文書 d のベクトル、
  x̄ はその層の文書ベクトルを全文書で平均したベクトル (主成分を推定するときに引く平均と同じ)、
  u_k は主成分 k の向き

### 文書の属性は、主成分得点との r² で見る

属性は次のとおりとする。

- 文書長
- 助詞の割合、形式名詞の割合
- 下記の助詞 10 語・助動詞 10 語・形式名詞 10 組のそれぞれについて、文書中の割合

主成分ごとに、全文書の (s_k(d), 属性の値) の組から Pearson の相関係数を出し、2 乗した r² を
指標にする。

主成分を推定したのと同じ文書で計算すると、異なる主成分の得点どうしの相関は 0 になる。そのため、
ある属性の r² を主成分 1〜k について足すと、上位 k 本の得点でその属性を線形回帰したときの
決定係数になる。属性のばらつきのうちどれだけがどの主成分にあるかを、内訳として読める。

### 語は、主成分ごとに標準化平均差 δ を計算して比べる

主成分 k の方向に強く寄る語を知るために、語 w ごとに文書を「w を含む」「w を含まない」の 2 群に分け、

> 標準化平均差 δ = (含む文書の s_k の平均 − 含まない文書の s_k の平均) ÷ 全文書の s_k の標準偏差

を出す。主成分ごとにすべての語についてこの値を計算し、値が大きい語 (含む文書が + 側に寄る語) と
小さい語 (− 側に寄る語) を調べる。

δ を計算する語は、意味や品詞では選ばない。全品詞の語を同じ一覧で扱い、選ぶ基準は語を含む文書の
数だけとする (助詞と助動詞は除く。下記)。

δ を計算するのは、含む文書が 1,000 件以上の語とする。ただし助詞と助動詞は δ を計算せず、
文書中の割合の r² で見る。助詞の「の」「を」「に」のように、ほぼ全文書に出て含まない群がほとんど
ない語があるためである。

### r² で見る助詞・助動詞・形式名詞

助詞と助動詞は、NTCIR-1 での出現回数の上位 10 語とする。形式名詞は品詞で取り出せないため、
ひらがなと漢字の表記の組で 10 組を一覧にする。

| | 語 (出現回数の多い順) |
|---|---|
| 助詞 | の (格助詞)・を (格助詞)・に (格助詞)・て (接続助詞)・は (係助詞)・と (格助詞)・が (格助詞)・で (格助詞)・から (格助詞)・も (係助詞) |
| 助動詞 | た・で・な・に・れ・る・られ・れる・られる・ない |
| 形式名詞 | (こと, 事)・(ため, 為)・(もの, 物)・(とき, 時)・(よう, 様)・(ところ, 所)・(ほか, 他)・(うち, 内)・(ほう, 方)・(まま) |

形式名詞は、表層形が組のどれかで、MeCab の読みがひらがなの表記の読みと一致するものだけを数える
(例: 「時」はトキと読んだものだけ数え、ジと読んだものは数えない)。MeCab が形式名詞と同じ読みを
付けた内容語の使い方 (人を指す「方」をホウと読んだものなど) は区別できないものとして扱う。

### 文書長を元に計算した標準化平均差を、語ごとに別に計算する

特定の語に着目した際に、長い文書ほど語を含む確率が高くなる。この時、文書長と相関する主成分が
存在した場合に、語の標準化平均差が文書長の影響で大きくなる可能性がある。

そこで語ごとに、同じ 2 群で主成分得点の代わりに文書長を使って標準化平均差を計算する
(含む文書の文書長の平均 − 含まない文書の文書長の平均、を全文書の文書長の標準偏差で割る)。
これは主成分の標準化平均差とは別に計算する。

### 数える範囲と品詞

- `document_text` (題名 + 抄録) をモデルの最大長 512 トークンで打ち切り (ADR-0004)、打ち切った後の
  文章を MeCab で語に分ける。語の有無と語の割合は、この語で数える
- 語の割合の分母は、同じ文章を MeCab で分けた語の数とする
- 文書長は、打ち切った後のモデルのトークン数とする
- 品詞は MeCab で取り、品詞が記号・補助記号の語は除く
- MeCab は Python の fugashi から、モデルのトークナイザーと同じ辞書 unidic-lite で使う
- 語は表層形・品詞の大分類・中分類の組で区別する。中分類がない品詞 (MeCab が `*` を返す。代名詞・副詞・
  助動詞・接続詞・接頭辞・連体詞) の語は、表層形と大分類の組で区別する

### 計算の結果を jsonl に書き、図は別のスクリプトで描く

計算するスクリプトは、全語・全主成分・全層の結果を jsonl に書く。図はその jsonl を読む別の
スクリプトで描く (`pc_removal` と同じ分け方)。jsonl はコミットしない。

```
output/<コレクション>/<モデル名>/
  words.jsonl            語、品詞、含む文書の数、文書長を元に計算した標準化平均差
  layer-LL/pc-KKK.jsonl  その層・その主成分での、語、品詞、標準化平均差 δ
```

層と主成分の番号はゼロ埋めにする。

図は層・主成分ごとに、|δ| の上位 100 語を、+ 側・− 側に伸びる横棒グラフで描く。語が多すぎて
読めないときは、載せる語の数を 50 語などに変えられるようにする。δ の符号は、同じ主成分の中で
語が同じ側か反対側かを読むために残す (主成分の向きは計算の都合で決まり、符号の向きそのものに
意味はない)。

## 確かめたこと

`cl-tohoku/bert-base-japanese-v3` の層 0、NTCIR-1 の全 332,918 文書で試した。

- 512 トークンで打ち切られる文書は 5,373 件
- 文書長 (モデルのトークン数) との相関は PC1 で r = −0.866、PC2 で r = +0.237
- 含む文書・含まない文書がともに 100 件以上ある 11,409 語で、PC1 の標準化平均差 δ と、
  「PC1 と文書長の r × 文書長を元に計算した標準化平均差」の相関は +0.920。PC2 では −0.257
- 「の」は 332,918 文書のうち 332,544 文書に出る
- MeCab の区切りでは「__-.&」のような記号の並びが 1 語になり、PC1 の標準化平均差 δ の上位に来る。
  unidic-lite ではこれらの品詞は「記号」になる
- unidic-lite では「こと」は「方法」と同じ名詞-普通名詞-一般で、形式名詞にあたる品詞がない
- 同じ表層形と大分類でも、中分類は出現ごとに分かれることがある。「の」(助詞) は格助詞 3,324,346 回、
  準体助詞 50,626 回、終助詞 10 回。数字は名詞-数詞になる (「7」は 24,235 回すべて名詞-数詞)

NTCIR-1 の全文書を上の手順で語に分け、表層形・大分類・中分類の組で区別して数えた
(`sandbox/analysis/word_frequency`)。

- 語は 238,577 種類
- 含まない文書が 1,000 件未満の語は「の」(助詞-格助詞、408 件) だけ、10,000 件未満の語は
  「の」「を」「に」(いずれも助詞-格助詞) の 3 語
- 含む文書が 100 件以上の語は 11,558 語。品詞は名詞-普通名詞 8,748、動詞-一般 933、接尾辞-名詞的 306、
  名詞-数詞 304、名詞-固有名詞 295、形状詞-一般 208、動詞-非自立可能 149、接頭辞 139 など
- 含む文書が 1,000 件以上の語は 2,807 語

形式名詞の漢字の表記を、NTCIR-1 の全文 (打ち切る前) で読みごとに数えた。

- 「時」は名詞-普通名詞でジ 45,235 回、トキ 12,968 回。ジは「3 時」のような時刻
- 「他」は名詞-普通名詞でタ 10,567 回、ホカ 7,741 回。タは「その他」
- 「方」は名詞-普通名詞でホウ 9,658 回、カタ 754 回。「あの方は」の「方」も MeCab はホウと読む
- 「外」はホカと読まれた例がない (名詞-普通名詞ではソト 2,016 回)
- 「事・為・物・所・様・内」は、形式名詞の品詞では形式名詞の読み (コト・タメ・モノ・トコロ・ヨウ・ウチ)
  がほぼすべて。ほかの読み (ブツ・ショ・ナイなど) はほぼ接尾辞で、「物」は接尾辞のブツが 61,819 回
- 「方法」「仕方」は MeCab で 1 語になり、「方」には分かれない

## 理由

- 属性に r² を使うのは、主成分をまたいで足せるからである。相関係数の絶対値 |r| は足しても
  意味のある量にならない。Spearman の相関係数では、足した値が決定係数と一致しない
- 語どうしの比較に r² を使わないのは、語の頻度が混ざるからである。語を含むなら 1、含まないなら 0
  とした値と主成分得点の相関は r ≈ δ × √(p(1−p)) (p は含む文書の割合) で、主成分を固定して
  語どうしを比べると、頻度の高い語が上に来る。δ はこの頻度の部分を除いた量で、含む文書の
  主成分得点が、含まない文書より + 側・− 側にどれだけずれているかを表す
- 標準偏差で割るのは、主成分や層によって得点の散らばりの幅が違い、平均の差だけでは
  比べられないからである。1 本の主成分の中での語の順位は変わらない
- 語を中分類まで区別するのは、層 1 以降は前後の文脈を取り込むため、同じ表層形でも品詞によって
  振る舞いが分かれるかを確かめられるようにするためである。中分類まで区別した記録は大分類の単位に
  まとめ直せるが、大分類で数えた記録を中分類に分けることはできない

## 採らなかった案

- **学会 (`SOCN`) との相関比 η²**: 学会と分野は一対一でなく、文書数も学会によって大きく偏る
  (59 学会のうち電子情報通信学会が 26%)。η² は主成分をまたいで足せない
- **頻出の内容語をまとめた割合を 1 つの属性にする**: 主成分の両極にある語が 1 つの割合の中で
  打ち消し合い、分野の軸が見えない
- **Cohen の d (2 群それぞれの中の標準偏差で割る)**: 含む文書が少ない語では値も順位もほぼ同じになる。
  全文書の標準偏差なら、主成分ごとに 1 つで済む
- **文書を文書長で 5 つほどの区間に分け、区間の中で δ を出す**: 層 0 で文書長との相関は PC1 が
  r = −0.866、PC2 が r = +0.237 で、PC3〜20 はほぼ 0 だった。文書長の影響が大きいのは PC1 で、
  そのために集計を区間の数だけ増やすのは見合わない
