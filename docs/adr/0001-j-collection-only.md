# ADR-0001: 対象を J コレクションのみとする

- Status: Accepted
- Date: 2026-08-30

## 背景

NTCIR-1 / NTCIR-2 には日本語文書集合 (J)、英語文書集合 (E)、日英混在 (JE) の
3 種の適合性判定が存在する。

## 決定

日本語文書集合 (J) のみを対象とする。

## 理由

- 検証対象モデルが日本語単言語モデル（tohoku-bert 系）であり、E / JE を扱うには
  多言語モデルの追加が必要になる
- 本研究の関心は「層・次元の選択が検索ベクトルに与える影響」であり、言語横断は
  独立した交絡要因になる

## 結果

- 実験軸が層・次元に集中する
- 「層・次元の傾向が言語に依存しないか」という問いは検証できない。将来 E を足す
  余地は残すが、Phase 1 / 2 の範囲外とする
