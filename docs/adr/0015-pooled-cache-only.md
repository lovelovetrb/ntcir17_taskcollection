# ADR-0015: 全件のプーリング済みキャッシュのみを作る

- Status: Accepted
- Date: 2026-08-31

## 決定

エンコード結果は、文書ごと・層ごとにプーリングしたベクトルとして保持する。
形は `[文書数, 層数, 次元数]`、全 332,918 件で 6.19 GB / モデル。

トークンごとの隠れ状態は保持しない。

## 理由

Phase 1 の実験（層ごとの検索性能と、ランダムに選んだ次元での性能分布。ADR-0006）
にトークンごとの情報は必要ない。

平均・最大・CLS のいずれのプーリングも次元ごとに閉じた演算であり、他の次元が
計算に関与しない。したがって「次元を選んでからプーリングする」と「プーリング
してから次元を選ぶ」は同じ結果を与える。プーリング済みで保持しても、層と次元の
選択に関して失われる情報はない。

なおトークンごとに保持すると 1.25 TB / モデルとなり、利用可能なディスク
(996 GB) に収まらない。

## 結果

- キャッシュは RAM に載る大きさに収まり、層と次元の組み合わせを多数試す実験が
  ディスク読み出しなしで回る
- 次元をまたいで値を混ぜるプーリング（注意重み付きなど）は扱えない
- トークンごとの解析が必要になった場合は、対象を限定して別途エンコードする。
  その際もプーリング済みのキャッシュとは別の構造として扱い、共通の抽象には
  まとめない
