# ADR-0014: 正規化は層ごとの L2 正規化を次元選択の後に適用し、その有無を実験軸とする

- Status: Accepted
- Date: 2026-08-31

## 決定

正規化を役割の異なる 2 つに分けて扱う。

**層どうしのスケールを揃える正規化**
次元を選んだ後に、層ごとに L2 正規化する。層を組み合わせるときに、特定の層が
内積を支配するのを防ぐ。

**検索ベクトルとしての正規化**
層を結合して最終的なベクトルを得た後に L2 正規化する。内積をコサイン類似度に
するために必要であり、層を 1 つしか使わない場合にも適用する。

前者の**適用の有無自体を実験軸**として扱い、適用した場合としない場合の両方を測る。

座標ごとの標準化（各次元を平均 0・分散 1 に揃える方式）は採用しない。

## 背景

Transformer は残差接続によって層を経るごとに隠れ状態のノルムが増大する。
NTCIR-1 の文書 64 件を平均プーリングして実測した。

| 層 | cl-tohoku/bert-base-japanese-v3 | cl-nagoya/unsup-simcse-ja-base |
|---|---|---|
| 0 | 3.84 | 3.80 |
| 4 | 10.27 | 10.52 |
| 8 | 12.22 | 12.35 |
| 11 | 18.25 | 16.18 |
| 12 | 12.45 | 13.33 |
| **最大 / 最小** | **4.8 倍** | **4.3 倍** |

内積への寄与はノルムの二乗に比例するため、層を連結したときの偏りはさらに大きい。

| 連結する層 | 各層の寄与 | 最大 / 最小 |
|---|---|---|
| 0, 4, 8, 12 | 3.5% / 24.8% / 35.2% / 36.5% | 10.5 倍 |
| 9, 10, 11, 12 | 18.4% / 26.7% / 37.4% / 17.4% | 2.1 倍 |
| 全 13 層 | 層 0 が 0.8%、層 11 が 18.3% | 22.6 倍 |

層 0, 4, 8, 12 を連結した場合、層 0 の寄与は 3.5% に留まる。正規化しなければ、
「4 層を組み合わせた」という条件が実質的に成立しない。

## 理由

### 次元選択の後に適用する

揃えるべきは実際に使う部分空間であって、捨てる次元を含めた全体ではない。
768 次元全体で単位長にしてから一部の次元を切り出すと、切り出した部分の長さは
層ごとに揃わない。ある層が選ばれなかった次元に大きな値を持っていた場合、
その層は正規化で縮められた上に、選んだ次元では過小な寄与しか持たなくなる。

### 有無を実験軸とする

関連研究
[layer-redundancy-detector#60](https://github.com/lovelovetrb/layer-redundancy-detector/issues/60)
で、座標のスケールを揃えるかどうかが STS の Spearman 相関に与える影響が
測定されている。

| ランダムに 768 セル選択 | 揃えない | 揃える | 差 |
|---|---|---|---|
| cl-tohoku/bert-base-japanese-v3 | 0.6100 | 0.7069 | +0.097 |
| cl-nagoya/unsup-simcse-ja-base | 0.7640 | 0.7076 | −0.056 |

**モデルによって符号が逆転する。** 影響の大きさは本研究が測ろうとしている効果に
匹敵するため、前処理として一度決めてよい事項ではない。同じランキングから
両方を計算でき追加コストがないため、常に両方を報告する。

### 座標ごとの標準化を採らない

座標ごとに平均と分散を揃える方式は、次元間のスケールの違いを消してしまう。
本研究の対象は次元ごとの差そのものであるため、それを消す前処理は目的に反する。
層ごとの L2 正規化であれば、層のスケール差だけを揃えて層内の次元構造は保たれる。

## 結果

- 層ごとの正規化の有無が実験軸に加わり、報告する構成が 2 倍になる。追加の計算
  コストはない
- 層を 1 つしか使わない構成では、層ごとの正規化は検索ベクトルの正規化と同じ
  結果になる。したがってこの軸が意味を持つのは層を複数使う構成のみである
