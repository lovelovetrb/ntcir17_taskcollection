# ADR-0006: Phase 1 の出力は層別性能とランダム次元の分散とする

- Status: Accepted
- Date: 2026-08-30

## 背景

先行して STS タスクで次元選択を試みている。手法は以下:

> 隠れ状態の層間差分を用いて、次の層の隠れ状態の各次元を SVR で予測するタスクを
> 構成し、MSE の上位順に次元を選択する

これはうまくいかなかった。この経験から得られる教訓は、**「次元選択の指標を設計
してから効果を測る」順序は、失敗したときに原因が切り分けられない**ということ。
指標が悪いのか、そもそも次元の選び方で性能が動かないのかが区別できない。

また、層の組合せによる文埋め込みの改善は STS で先行研究がある
（*BERT Has More to Offer: BERT Layers Combination Yields Better Sentence Embeddings*）。
本研究の新規性は層ではなく**次元**の粒度にある。

## 決定

Phase 1 の出力を以下の 2 つとする。

### (1) 層ごとの検索性能

13 点（埋め込み層 + 12 層）× 2 モデル。

位置づけは**土台であって主張ではない**。層の粒度は先行研究があり、本研究の
貢献ではない。検索タスクでも同様の傾向が出るかを確認し、以降の次元実験の
基準点を得るために行う。

### (2) ランダム k 次元での性能分布

k を変えながら、各 k につき複数シードでランダムに次元を選び、性能を測る。

**着目するのは平均値ではなくシード間の分散**である。

- 分散が小さい → どの次元を選んでも性能が変わらない → **次元選択に余地がない**
- 分散が大きい → どの次元を選ぶかが効く → **次元選択に余地がある**

## 理由

この設計なら、次元選択の指標を一切設計せずに、教師なしで、Phase 1 の問い
（次元選択に意味があるか）に答えられる。指標の良し悪しと余地の有無が分離される。

## 結果

- Phase 1 では教師あり次元選択を実装しない。したがって過学習・リークの論点は
  Phase 1 には存在しない
- Phase 2 に進む判断基準は「ランダム次元の分散が十分に大きいこと」となる。
  具体的な閾値は測定結果を見てから定める
- 分散が小さいという結果が出た場合、それ自体が知見であり、Phase 2 は中止する
