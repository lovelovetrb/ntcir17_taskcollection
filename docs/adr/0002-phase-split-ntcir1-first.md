# ADR-0002: Phase 1 は NTCIR-1 単独で行う

- Status: Accepted
- Date: 2026-08-30

## 背景

次元選択を教師ありで行う場合、768 次元に対してトピック数が少ないため過学習が
避けられない。NTCIR-1 (83 トピック) を選択用、NTCIR-2 (49 トピック) を評価用に
分けることで、リークのない検証が構成できる。

一方で、「そもそも次元の選び方によって検索性能が変わるのか」はまだ未検証である。

## 決定

段階を 2 つに分ける。

- **Phase 1**: NTCIR-1 単独。層・次元の粒度で性能が動くかを観測する
- **Phase 2**: Phase 1 で次元選択の余地が確認された場合のみ着手。NTCIR-1 で
  次元を選択し、NTCIR-2 で評価する

## 理由

未検証の仮説（次元選択に意味がある）に対して、先に評価基盤の二重化コストを
払うことになるため。Phase 1 で余地がないと分かれば、Phase 2 の実装は不要になる。

## 結果

- Phase 1 のコーパスは `mlir/ntc1-j1` の 332,918 件のみ（ADR-0009）。NTCIR-2 の
  403,240 件は Phase 2 まで触らない
- Phase 1 の設計は Phase 2 での拡張を妨げないこと。特に:
  - 文書 ID 規約が両コレクションで異なる (`gakkai-` / `gakkai-j-`) ため、
    正規化層を最初から入れる
  - 適合度グレード体系が異なる (NTCIR-1: A/B/C、NTCIR-2: S/A/B/C) ため、
    gain 関数をコレクション固有の設定として持たせる
