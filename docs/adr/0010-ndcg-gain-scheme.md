# ADR-0010: nDCG の利得は線形の A=2, B=1, C=0 とする

- Status: **Superseded in part by [ADR-0011](0011-follow-transfer1-protocol.md)**
  （`A=2, B=1, C=0` という数値の割り当ては Transfer-1 と同一で有効。ただし評価は
  graded ではなく `rel >= 1` の 2 値で行う。以下の本文は決定当時の記録として残す）
- Date: 2026-08-30

## 決定

nDCG の利得を以下とする。

```
gain(A) = 2   （適合）
gain(B) = 1   （部分的に適合）
gain(C) = 0   （非適合）
gain(未判定) = 0   （ADR-0007）
```

割引は原論文 (Järvelin & Kekäläinen 2002) の線形形式を用いる。

```
          k   gain(gᵢ)
DCG@k  =  Σ  ──────────
         i=1  log₂(i+1)

nDCG@k = DCG@k / IDCG@k
IDCG@k = qrels 内の全文書を利得の降順に並べた理想ランキングの DCG@k
```

## 検討した選択肢

| 案 | 内容 |
|---|---|
| `A=1, B=0` | B を非適合として捨てる（rel1 の 2 値化と同じ） |
| `A=2, B=1` | 線形利得。採用 |
| `A=3, B=1` | 指数利得 `2^gain − 1` を線形形式で書いたもの |

`A=3, B=1` は独立した案ではなく、`{A:2, B:1}` を指数利得
`(2^gain − 1) / log₂(i+1)` で評価したものと同一である。

## 理由

### B の分布は極端に偏っている

```
全体         A=4,962   B=752      B は適合(A+B)の 13.2%
B が 0 件のトピック      22 / 83
B が A より多いトピック  12 / 83

topic 0033:  A=13,  B=145   B が適合の 91.8%
topic 0054:  A=577, B=2     B が適合の  0.3%
```

大半のトピックでは利得の選択が結果に影響しないが、少数のトピックでは決定的になる。

### シミュレーションによる検証

性能を段階的に変えた 40 個の仮想システムを生成し、利得の置き方を変えたときに
システムの順位がどれだけ入れ替わるかを Kendall の順位相関係数 τ で測った
（τ = 1.0 なら順位が完全一致、低いほど入れ替わりが起きる）。

| 比較 | τ（A/B を出現比どおりに引く場合） | τ（システムごとに A 選好 / B 選好が異なる場合） |
|---|---|---|
| `A=1,B=0` vs `A=2,B=1` | +0.972 | **+0.921** |
| `A=1,B=0` vs `A=3,B=1` | +0.980 | **+0.939** |
| `A=2,B=1` vs `A=3,B=1` | +0.992 | **+0.982** |

- **線形 (2:1) と指数 (3:1) は区別できない**（τ ≈ 0.98〜0.99）。どちらを選んでも
  同じ結論が出るため、原論文の形式である線形を採る
- **意味があるのは B を使うか捨てるかの方**（τ が 0.921 まで低下）。ペア比較の
  約 4% が入れ替わる。数百構成を掃く実験では無視できない
- B を捨てると、B が適合の大半を占めるトピック 12 件が機能しなくなる

なお上記は仮想システムのモデルに基づくシミュレーションであり、層や次元を変えた
構成が実際に A 選好 / B 選好の点でどれだけばらつくかは未知である。ばらつきが
小さければ τ はさらに 1.0 に近づき、この判断のリスクは下がる。

## 結果

- nDCG は `|R|`（そのトピックの適合文書数）の偏りの影響を受けない。IDCG が
  「そのトピックで達成可能な最良値」であるため、適合文書が 3 件でも 1,410 件でも
  上限が 1.0 に揃う。Recall@k とは対照的である（ADR で別途扱う）
- MAP / Recall / Precision は 2 値の適合判定を要するため、`rel1` 相当（A のみ）と
  `rel2` 相当（A と B）の両方を報告する。2 値化は grade 列から導出する
