# ADR-0018: 隠れ状態は PyTorch テンソルとして保持し、キャッシュ全体を GPU に載せる

- Status: Accepted
- Date: 2026-08-31

## 決定

隠れ状態を PyTorch のテンソルとして保持する。実験時はキャッシュ全体を一度だけ
GPU に転送し、層と次元の絞り込み、ベクトルの構成、検索をすべて GPU 上で行う。

## 理由

キャッシュ全体が GPU に収まる。

```
文書キャッシュ全体  [332,918, 13, 768] fp16      6.19 GB
1 構成を実体化      最大 (全 13 層 x 768 次元)   6.19 GB
スコア行列          [83, 332,918] fp32            105 MB
                                                ────────
                    合計 12.6 GB   A100 80GB に対して余裕がある
```

したがって構成ごとにホストとデバイスの間でデータを往復させる必要がない。
層と次元の絞り込みは GPU 上のインデクシングとなり、遅延評価などの工夫なしに
素直に実体化してよい。

エンコードの出力も検索の行列積も PyTorch であるため、間に NumPy を挟むと構成
ごとに 6 GB 規模の転送が発生する。

また PyTorch であれば、テンソルが CPU 上にあっても GPU 上にあっても同じ操作が
書ける。テストでは CPU 上の小さなテンソルを使い、実験では GPU に載せるという
使い分けが、同じコードのままで成り立つ。

## 結果

- PyTorch のテンソルは可変であるため、絞り込みが元のテンソルを壊さないことを
  実装時に保証する必要がある
- fp16 で保持するため、検索時の内積で精度が問題にならないかを確認する
