# ADR-0007: 検索対象は全文書とし、未判定文書は非適合として数える

- Status: Accepted
- Date: 2026-08-30
- 当初 Deferred で起票し、議論を経て Accepted に更新した

## 決定

検索対象を `mlir/ntc1-j1` の **全 332,918 件**とする。
qrels に判定が存在しない文書が上位に現れた場合、**非適合 (gain 0) として数える**。

bpref、condensed list、プール内再ランキングのいずれも採用しない。

## 背景

適合性判定はプーリングで作られている（`MANUAL-E.PDF` 5.1）。参加各ランの上位文書を
集めて和集合を取り、それに人手の recall 志向検索を加えたものがプールである。
プールに入らなかった文書は判定されず、非適合とみなすと明記されている。

その結果、1 トピックあたりの判定済み文書は全文書の約 1% に留まる。

```
qrels 行数 (= (topic, doc) ペア)   261,173
1 トピックあたり判定数             平均 3,147 (min 1,532 / 中央 2,519 / max 7,732)
1 トピックあたりの判定率           332,918 件中 0.69% 〜 2.09%
```

判定済み文書のユニーク数は 120,359 件（全体の 36.2%）だが、**これは評価の判断材料に
ならない**。1 文書は平均 2.17 トピックについてしか判定されておらず、他トピック用の
判定は当該トピックの評価に使えないため。

## 検討した選択肢と、それらが同一である理由

未判定文書問題への対処として知られる手法を検討した結果、**スコア順に並べる
システムにとって、これらはすべて同一の評価になる**ことが分かった。

| 手法 | 未判定文書の扱い |
|---|---|
| PerTopicPool（プール内再ランキング） | 候補集合に入れない |
| condensed list (Sakai 2007) | ランキングから除去してから指標を計算 |
| bpref (Buckley & Voorhees 2004) | 指標の計算で数えない |

本研究のシステムはコサイン類似度でスコアを付けて降順に並べるだけである。
**部分集合を取る操作はスコア順を保存する**ため、

```
全 332,918 件をスコア順に並べる → 未判定を除去 → 判定済み文書がスコア順に並ぶ
判定済み 3,147 件だけをスコア順に並べる       → 判定済み文書がスコア順に並ぶ
```

この 2 つは同じ並びを与える。IDCG も同一の qrels から作られるため、nDCG も MAP も
完全に一致する。したがって選択肢は実質的に 2 つしかない。

- **A. 未判定を非適合として数える** — 真の検索タスク
- **B. 未判定を評価から除外する** — 再ランキング。上記 3 手法はすべてこれ

## 理由

B を採らないのは、**第一段階検索の性能が評価に一切入らない**ため。プールは 1999 年
当時の参加システムが選んだ候補であり、B はそれらが第一段階検索を代行してくれた
前提に立つ。本研究の目的は RAG で用いるベクトルの評価であり、332,918 件から
関連文書を見つけ出す能力そのものを測りたい。それを測れない評価は目的に合わない。

## 結果 — 受け入れる制約

- **得られる nDCG / MAP は真の性能の下限である。** 1999 年当時のどのシステムも
  上位に出せなかった適合文書を本手法が見つけても、判定がなければ加点されず、
  むしろ非適合を上位に出したものとして減点される
- **絶対値を外部と比較しない**（ADR-0005 と整合）。比較は常に本研究内の構成間で行う
- **「全構成が同じバイアスを受けるので構成間比較は成立する」は厳密には保証されない。**
  語彙一致から遠い挙動をする構成ほど未判定文書を引きやすいという偏りはあり得る。
  この選択をする限り測定できないため、制約として明記して受け入れる
- 上位 k 件のうち qrels に判定が存在する割合を**診断値**として記録する。過小評価の
  程度を知るための参考情報であり、指標の代替ではない。これは確立した指標名を
  持たない単なる健全性チェックである
