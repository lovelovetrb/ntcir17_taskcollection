# ADR-0033: 品詞の大分類の割合も主成分得点との r² と散布図で見ることにし、分析の名前を pos_ratio にする

- Status: Accepted
- Date: 2026-11-07
- ADR-0031 の分析の名前・置き場、指標、個別に見る語を選ぶ線を置き換える

## 背景

ADR-0031 の分析を `cl-tohoku/bert-base-japanese-v3` で回すと、層 0 の PC2 と助詞全体の割合の相関は
r = 0.56 だった。ただし、品詞の大分類ごとの割合で比べると、名詞の割合のほうが PC2 と強く相関した
(NTCIR-2 の全文書)。

| 品詞 | PC2 との r (層 0) |
|---|---|
| 名詞 | −0.58 |
| 助詞 | +0.57 |
| 動詞 | +0.36 |
| 助動詞 | +0.12 |

割合は足すと 1 になるため、名詞と助詞の割合は逆に動く (r = −0.69)。一方を固定した偏相関は、
助詞が +0.28、名詞が −0.33 で、どちらも残る。助詞の割合だけを見ても、PC2 が助詞と名詞のどちらに
対応するのかを区別できない。

品詞の大分類ごとの出現回数と、その品詞の語を含む文書の数を NTCIR-2 の全文書 (736,158 件) で
数えた (`sandbox/analysis/pos_frequency/`)。語は ADR-0031 と同じく、512 トークンで打ち切った後の
文章を MeCab (unidic-lite) で分け、記号・補助記号を除いた。

|---|---|---|---|---|

## 決定

### 分析の名前と置き場

助詞・助動詞に限らない語の割合の分析になるため、名前を `particle_ratio` から `pos_ratio` にする。

```
src/pca/analysis/pos_ratio/
results/pca_analysis/pos_ratio/ntcir2/<model_id>/
  correlations.jsonl                   指標・層・主成分・グループごとの r と r² (16 × 13 × 9 × 3 = 5,616 行)
  figures/<指標>/layer-LL-<グループ>.png  (16 × 13 × 3 = 624 枚)
```

対象 (コレクション・主成分・層・グループ)、語の数え方、割合の分母、記録と図の形は ADR-0031 のままとする。

### 指標

文書ごとに、次の 16 個の割合を出す。

- 品詞の大分類 7 個: 名詞、助詞、動詞、助動詞、接尾辞、接頭辞、形状詞
- 助詞 8 語: の・を・に (格助詞)、て (接続助詞)、は (係助詞)、と・が・で (格助詞)
- 助動詞 1 語: た

品詞の大分類も個別の語も、NTCIR-2 の全文書のうち 85% 以上に含まれるものとする。個別の語は、
ADR-0031 の 88% の線と同じ 9 語になる (88.3% の「で」の次は、50.8% の「から」)。

## 理由

- 名詞・動詞の割合も同じ手順で見れば、PC2 が助詞・名詞・動詞のどれと強く対応するかを並べて比べられる
- 品詞の大分類の条件は、ADR-0031 の個別の語と同じく、品詞で絞った語の割合として数えられる
- 線を 85% にすると、接頭辞と形状詞が入る。どちらも割合 0 の文書が約 15% あり、1 文書あたりの回数も
  平均 3 回ほどで、ADR-0031 で入れた「で」(格助詞、割合 0 の文書 11.7%、平均 3.1 回) とほぼ同じである。
  散布図では、割合 0 の文書が左端に縦に並び、回数の少ない文書が 1/n・2/n の曲線に並ぶ。「で」と
  同じく、これを分かったうえで r² を読む

## 採らなかった案

- **線を 88% のまま (名詞・動詞・接尾辞だけを足す)**: 接頭辞と形状詞は、すでに入れている「で」と
  含む文書の割合も回数もほぼ同じで、外す理由にならない
- **形容詞を入れる**: 割合 0 の文書が全体で 33.8%、学会発表で 42.8% あり、含む文書でも平均 2.5 回で
  ある。割合の r は含むか含まないかの差に近くなり、issue #93 の δ と同じ中身になる。#93 で、文書長の
  影響を外した δ で見る
- **`particle_ratio` を残し、品詞の大分類を別の分析にする**: 対象・数え方・記録の形がすべて同じで、
  指標の一覧が違うだけになる

## 結果

- ADR-0031 の Status を `Superseded in part by 0033` にする
- 実装の PR (#107) を、マージする前に `pos_ratio` に名前を変え、指標を 16 個にする
- #93 の issue に、形容詞を δ で見ることをコメントする
